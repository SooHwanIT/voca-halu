# 작은 움직임 명세 (2차)

1차(2026-09-30): 정답 오른쪽·오답 왼쪽으로 날아가기, 팩이 아래에서 올라오기, 한 팩 더·닫기 전환,
진행 점, 보기 버튼 반응, 모은 카드 숫자 올라가기, 충전 칸 차오름, 선반 딸깍.

2차 기준: **자주 보는 화면부터**, 한 번 보면 알아채지만 방해하지 않는 것. 새 화면·새 규칙은 만들지 않는다.

## 공통 규칙
- 움직임 줄이기(`prefers-reduced-motion`)를 켜면 움직임은 모두 빠진다. 소리와 진동은 그대로 둔다(효과음 끄기 설정을 따름).
- 한 번의 조작에 효과는 하나만 크게. 이미 큰 효과(레벨 업·새 버전·금색 카드)가 나는 순간에는 더하지 않는다.
- 길이: 조작 반응 0.15~0.4초, 알림성 움직임 0.6초 안.
- 숫자·글자는 실제 값만 보여 준다(꾸민 숫자 없음).

## 하지 않는 것
- 기기 기울기(자이로)로 카드 움직이기: iOS 권한 요청이 필요하다(첫 60초 규칙과 충돌).
- 콤보 보상(가루 추가 등): 규칙이 바뀌는 일이라 이번 범위가 아니다.
- 결과 숫자 올라가기(가루 +N): 라벨이 짧게 바뀌는 자리라 오히려 읽기 어렵다.
